# 像素光影 · 画法

一句话：**像素永远是锐利的小方块，"高级"来自光**：按光源算出来的亮层和暗层、发光体和够亮的像素四周那圈淡淡的泛光、空气里的雾和光柱、湿地上的倒影，加上近景的背景虚化。任何时间都是这样：夜里光来自灯，白天光来自太阳和亮的表面，黄昏两样都有。

## 1. 两支参考片

**「给我一首歌的时间」MV**：雨夜河边，人物约 80 像素高，迎着路灯一侧有 1 像素暖橙轮廓光，另一侧压暗；路牌、霓虹、楼窗、列车窗本身是锐利的像素，四周叠一圈很淡的柔光；近景背景整体虚化；雨、溅起的水花、路灯在湿地上拉出晃动的倒影。

**「圣诞星」MV**：像素大小全片统一，颜色块干净、饱和；人物基本平涂，没有亮层暗层。

**取舍**：光照前者做（亮边、暗面、柔光、雨、虚化）；像素照后者做：镜头推近时不放大像素，而是按新的缩放重新画，近景的脸像素更多，表情更清楚。近景的背景虚化照前者保留。

## 2. 八条规矩

### ① 分辨率和密度

- 所有东西画在 480×270 上（`px.js` 的 `LW × LH`），最后 ×4 最近邻放大到 1920×1080。
- 镜头推近不放大像素。`camera(x, y, z)` 把世界坐标乘上 z 再画，z = 3.4 时人物有 200 多像素高。
- 人物细节按身高 H 自动换档（`people.js` 的 `face()`）：

| 身高 H（像素） | 眼睛 | 其他 |
|---|---|---|
| ≥ 180 | 3×4，两点高光 | 4 像素的眉毛，5 像素的笑嘴，2–3 像素的腮红 |
| 110–180 | 2×3，一点高光 | 眉毛、嘴、腮红 |
| 70–110 | 1×2 | 2 像素的嘴、1 像素的腮红 |
| < 70 | 1 像素 | 只看剪影和动作 |

- 要让观众看清表情，就推到 H ≥ 180（大腿以上的中景）。全景只交代地点、光和关系。

### ② 光源驱动的亮层和暗层（最重要）

不手画亮暗，全部按光源算（`px.js` 的 `shade()`）。

- **光源**：`{ x, y, c: 颜色, k: 强度 0–1, r: 影响半径 }`，屏幕坐标。路灯、窗、车灯、霓虹、信号灯这些零件都会返回自己的光源。太阳和天光是平行光（`dir: true`，放在很远的地方），由 `env.js` 给（`envLights()`）。
- **材质图**：人物先画成材质图 `Mat`，每个像素记材质（每种四档颜色：最暗、暗面、本色、亮面）和部件（头、躯干、上臂……明暗按部件自己的中心算，每一节都像一根小圆柱）。
- **`shade()` 对每个像素做的事**：
  1. 按主光（对这个人影响最大的光）分出暗面和亮面。明暗交界用 4×4 抖动做一条窄带，别太宽，否则像棋盘格。
  2. 迎光方向的邻居是空的，这个像素就是轮廓光：亮面色往光的颜色混 35%–85%，强光时 2 像素宽，同时往发光层加一点。
  3. 副光照同样的办法，在另一侧给第二道亮边：夜里一暖一冷，白天是太阳加天光。
  4. 背光方向的邻居是空的，降一档；外面描一圈深色，但轮廓光旁边不描。
- **逆光**（`o.back`，太阳低、在人物身后）：正面整体落进暗面，只有边亮，亮边更亮、往发光层加得更多。黄昏、清晨的"高级感"主要靠它。
- **调色**（`o.grade`）：白天亮面往太阳色偏，暗面往天光色（偏蓝紫）偏。夜里不调。
- **光源动，亮边跟着动**：车从身后开过，冷白亮边就从一侧扫到另一侧，不用额外写代码。
- 五官用单色材质（`flat`），不受光。

### ③ 发光层和泛光：任何时间都有

- **发光层 `emis`**：窗、灯头、车灯和拖影、霓虹、信号灯、光锥、轮廓光，画进背景的同时写进发光层。
- **亮部提取 `brightPass()`**：白天画面里几乎没有灯，所以把够亮的像素（太阳周围的天、逆光的亮边、白衣服、玻璃和水面的反光）也按超出阈值的多少加进发光层。阈值和强度由钟点定（`ENV.post.bright`），夜里关掉。
- **三级泛光**（`post.js`）：发光层缩到 240×135、120×68、60×34，各自模糊再放大，用 `lighter` 叠上去，外加一层原尺寸的软光。像素本体不糊，只有外面那圈光是软的，看起来就是"像素在向外发出微弱的光"。
- **太阳**：日盘是锐利的像素圆，周围一圈抖动的暖色光晕画在天空里；光晕写进发光层要等所有图层画完，只加到没被楼和人挡住的天空上（`skyLight()`，`frame.js` 里自动调）。
- **光柱**（`rays`）：从太阳往外放射，被楼挡住的地方就断开。
- **眩光**（`glare`）：太阳附近一大片柔和的暖光，太阳被楼挡住也有。近景里看不到太阳，逆光的感觉靠它。
- **浮尘**（`motes()`）：阳光里飘的小亮点，一闪一闪，放在逆光的地方（人物身后、窗前）。不下雨时才有。
- 强度：`bloom` 默认 1，近景、情绪高的地方 1.05–1.2；雾气 `haze` 约 0.14（白天自动减到约 0.1）。

### ④ 时间和天气（`env.js`）

每帧画之前：`applyEnv(makeEnv({ hour, weather, sunX }))`，`frame.js` 按镜头的 `env`（没有就用 `shots.js` 的 `ENV_DEFAULT`）自动做。

- `hour`：0–24 的钟点。由它算出太阳高度，再算出下面所有东西。
- `weather`：`"clear"` 晴、`"cloudy"` 阴、`"rain"` 雨（阴天下雨）、`"sunrain"` 太阳雨（有太阳也下雨）。下雨不再等于晚上。
- `sunX`：太阳在画面里的左右位置（0–1）。决定逆光从哪边来、影子往哪边倒。放在楼和楼之间的空当里，太阳才看得见。

| 跟着钟点变的 | 夜里 | 清晨 / 黄昏 | 白天 |
|---|---|---|---|
| 天空 | 7 档深紫 | 清晨淡紫到浅杏，黄昏蓝紫到橙 | 蓝到浅蓝 |
| 主光 | 路灯（暖橙） | 低低的太阳，逆光 | 高处的太阳，影子短 |
| 窗 | 约四成亮着暖灯 | 一盏盏亮起来 | 玻璃映着天，几扇反射太阳闪一下 |
| 路灯、车灯 | 开 | 渐渐开 | 关（尾灯还微微亮） |
| 楼 | 暗靛 | 背光压暗偏冷，远楼成剪影，受光边是亮的 | 白天的颜色，远处靠近天色 |
| 地面 | 暗、湿 | 黄昏接住斜阳偏暖，清晨被雾冲淡 | 浅灰，下雨时映着天色 |
| 影子 | 无 | 很长，朝镜头这边倒 | 短，在脚下 |
| 空气 | 无 | 清晨有雾，远处蒙一层天色 | 远处淡淡蒙一层 |
| 后期 | 原样 | 眩光、光柱、轻微暖色（清晨偏粉） | 亮部泛光、暗角变淡 |

- **夜里和原来完全一样**：`makeEnv({ hour: 21, weather: "rain" })` 画出来和只有夜景时的版本逐像素一致。
- **白天要克制**：只让最亮的一小部分发光，暗部保持干净、偏冷。光晕一多就灰蒙蒙，像素的利落感没了，脸上的表情也会糊。
- **最出效果的是逆光**：太阳在人物身后、低，楼和人的正面都在背光里，只有边亮，天是亮的。正午最平，靠云、反光和亮部泛光撑。
- **时间流逝不用切镜头**：同一个镜头里把 `hour` 随时间推进（镜头对象的 `env` 写成随 `T` 变的也可以），窗灯会一盏盏亮起来。
- 默认关键时刻：清晨 6.4、正午 12.5、黄昏 17.6、夜里 21。

### ⑤ 雨和湿

- **雨**（`rain`）三层：远的 1×2 暗淡、慢；中的 1×4；近的 1×7 亮、快，画在 fg 上挡在人前面。整体斜 0.14。
- **被照亮的雨**：离灯越近越亮、带上灯的颜色；太阳雨里，靠近太阳那一侧的雨丝会发光。
- **伞下的干区**：`umbrella()` 返回干区，雨和水花都跳过。不下雨时不打伞。
- **水花**（`splashes`）：地上一闪就没的 ∧；人没被伞盖住时，头顶、肩上也溅。
- **水洼**：映着天，有一圈亮边，千万别比地面暗，否则像洞。白天的水洼就是一小块天色。
- **倒影**：`reflect` 把发光层里一条横线以上的东西竖着拉长、左右晃，加到湿的地方；`streak` 在高处的灯（路灯、信号灯、橱窗）正下方画一条竖着晃、断断续续的光带。太阳低时在湿路面上拉一条宽的暖色光带。
- 湿度 `ENV.wet`：下雨时是 1，晴天是 0（没有水洼和倒影）。雨后初晴可以 `makeEnv({ weather: "clear", wet: 0.6 })`。

### ⑥ 景深

- 背景层 `bg` 和主体层 `fg` 分开画。镜头返回 `dof`（1080p 像素），近景 3–5，全景 0。
- 近景人物身后**要有一条亮东西**：亮着窗的公交车、列车、橱窗。虚化后变成散景，人物的剪影和亮边才跳得出来。

### ⑦ 色板（`palette.js`）

- **`PAL_NIGHT`** 夜里的颜色，**`PAL_DAY`** 白天的颜色（只列会变的）。零件只读 `PAL`：`applyEnv()` 每帧按钟点把两套混好写进去（黄昏偏暖、阴天偏灰、下雨地面变深、逆光时楼压暗），天空单独算。
- 发光的东西（灯、车灯、信号灯、霓虹、窗光）白天黑夜同一个颜色，亮不亮由 `ENV` 决定。
- 人物材质 `MATS` 每种四档，不随时间变，明暗交给打光。夜里本色要压暗，让轮廓光去提亮。
- 换片子、换气氛先改色板。例如雪：天空偏蓝，地上白，水洼换成积雪，路灯暖光保留。

### ⑧ 人物和镜头

- 约 6 头身。`pose`：`f` 朝向；`armN`、`armF` 肩角和肘弯；`walk`、`bob`、`nod`；`eyes`（open、half、closed、happy、wide）；`mouth`（line、smile、open、o）；`blush` 0–1；`brows`（flat、sad、up）。
- 手要正好碰到某处（牵手、递东西、碰伞）：`reachTo()` 反向求出 `[a, b]`，再和平常的姿势按时间插值。
- **影子**（`castShadow(bg, R, 脚底 y)`）：有太阳时把人投到地上，在画人之前调。太阳越低影子越长。
- 透明伞：`part: "shaft"` 先画伞柄（在人后面），打完光再 `part: "canopy"` 画伞面。举伞的手藏在肩后（`armF ≈ [-0.2, 3.25]`）；歪伞不超过 0.25 弧度，伞柄约 0.74H。逆光时整把伞透着光。
- 镜头：先全景（z ≈ 1）交代地点和光，再推到双人中景（z ≈ 3.3–3.6）看表情。一个镜头只做一种慢动作。动作顶点落在字上：`src/cues.js`（见 workflow.md 第 4 步）。

## 3. 代码结构

```
index.html              一张 1920×1080 canvas + 一条音轨；src/main.js 在 hf-seek 里画
src/main.js             每帧 drawFrame() → post.finish() → 像素字幕
src/frame.js            画一帧的公共步骤：设时间和天气 → 清空三层 → 镜头 draw() → skyLight() → brightPass()
src/shots.js            分镜表 SHOTS 和全片默认的 ENV_DEFAULT（钟点、天气、太阳位置）
src/scenes/*.js         镜头：draw({ bg, fg, emis, T, lt }) 返回 { dof, bloom, haze, tint }
src/env.js              makeEnv()、applyEnv()、ENV、envLights()：钟点和天气 → 光
src/px.js               Pix、Mat、形状测试、shade()、bayer()
src/world.js            camera()、sky、skyline、apartment、store、road（cars 里加 bus: true 就是公交）、sidewalk、
                        reflect、streak、lamp、walkSignal、rain、splashes、motes、snap/aerial（空气透视）、skyLight
src/people.js           LOOKS、drawPerson()、shadePerson()、castShadow()、reachTo()、umbrella()
src/palette.js          PAL_NIGHT、PAL_DAY、PAL、MAT、MATS
src/post.js             createPost().finish()、brightPass()
src/subs.js             drawSubs()、linesFromTiming()
src/cues.js             动作踩字
tools/layers/           分层拆解四格
tools/times/            时段对比四格
```

**一个镜头的写法**（照 `scenes/rain-hands.js`）：

1. `const cam = camera(x, y, z)`：世界坐标是全景时的像素，`cam.L(d)` 是第 d 层的视差变换（0 天空、0.15 远楼、0.5 中景楼、0.75 马路、1 人行道和人物）。
2. 背景从远到近画：`sky(bg, emis, T)` → 远楼 → 中景楼 → 马路 → 人行道 → 路灯、信号灯。每画完一层远处的东西，用 `before = snap(bg)` 和 `aerial(bg, before, 远近)` 给它蒙一层天色。把零件返回的光源收进数组，`envLights()`（太阳、天光）放最前面。
3. 有湿度时画倒影（`reflect`、`streak`）。它们读发光层，要放在所有发光零件之后。
4. 人物：`drawPerson()` → `castShadow()` → `umbrella(…, part: "shaft")` → `shadePerson()` → `umbrella(…, part: "canopy")`。
5. 下雨：`rain`、`splashes`（传 `dry`）；不下雨：`motes`。
6. 返回后期参数。太阳光晕、亮部泛光、光柱、眩光不用管，`frame.js` 和 `ENV.post` 会补上。

**光源顺序**：`shadePerson` 会按"对这个人的影响"重新排序取前两个，场景里只管把光源都收进来。

**换钟点**：改 `shots.js` 的 `ENV_DEFAULT`，或者给某个镜头加 `env`，例如 `{ ...streetTwo({ tIn, tOut }), env: { hour: 6.4, weather: "clear", sunX: 0.36 } }`。

**低配像素风**（教程里演示过的 320×180、限 16–32 色、角色逐帧换画）也用这个模板：把 `px.js` 的 `LW`、`LH` 改小，色板减色，后期的 `bloom`、`haze` 设成 0。

```bash
npx -y hyperframes@0.9.41 snapshot tools/layers --at 27.7 --no-end -o renders/_layers --timeout 170000   # 分层拆解：背景、加主体、发光层、成片
npx -y hyperframes@0.9.41 snapshot tools/times --at 23.2,27.7 --no-end -o renders/_times --timeout 170000  # 时段对比：同一刻换四个钟点和天气
```

## 5. 踩过的坑

- **白天发白发灰**：泛光、雾气照搬夜里的强度，整张都蒙了。白天只提最亮的一小部分（`brightPass` 阈值 0.77 左右），雾气减到夜里的六七成。
- **黄昏的楼像被正面照亮**：太阳在楼后面，朝镜头的墙应该在背光里。`applyEnv()` 按逆光程度把楼压暗、偏冷，远楼成剪影，受光边提亮。
- **清晨和黄昏分不出来**：清晨的天偏淡紫到浅杏，太阳偏粉白，雾更重，路灯还没关；黄昏的天蓝紫到橙，地面接住暖光。
- **太阳的光晕盖在楼上**：光晕先画在天空里，进发光层前要检查这个像素还是不是天空（`skyLight()` 比对天空画完时的快照）。
- **空气透视把天空的快照弄坏了**：雾只蒙"这一层新画的像素"（`snap` + `aerial`），不蒙整张。
- **近景里看不出是黄昏**：近景看不到太阳，靠眩光（`glare`）、逆光的人和偏暖的地面交代。
- **白天的水洼像一块灰板**：水洼和湿地面要映天色，`applyEnv()` 下雨时会自动做。
- **太阳被楼全挡住**：`sunX` 放在楼和楼之间的空当里。
- **伞像飘在头上**：伞柄用亮一档的颜色，近景画 2 像素宽。
- **举伞的手在胸前像个拳头**：远侧手臂举在肩后，`[-0.2, 3.25]`。
- **伞沿切过另一个人的头**：歪伞不超过 0.25，伞柄 0.74H，伞面 rx 0.4H。
- **橱窗虚化后像一块白板**：橱窗颜色压暗，发光强度 0.32，加窗框和货架。
- **路灯在地上没有倒影**：`reflect` 只能反到轴线附近，高处的灯要用 `streak`。
- **信号灯红转绿看不见**：灯箱在中景里出画了，就靠它在水洼里的倒影交代。
- **车窗里的乘客剪影虚化后像一排字**：少放（四分之一的窗）。
- **近景身后一片黑**：放一条亮东西（公交车窗）做散景。
- **人行道的抖动纹理在近景里变成噪点**：纹理坐标要除以镜头缩放，`world.js` 里已经这么做了。
- **明暗交界的抖动带太宽像棋盘格**：阈值范围收到 0.16。
- **衣服太亮像在发光**：夜里的本色压暗，让轮廓光去提亮。
- **`ReferenceError` 让整个合成起不来**：`snapshot` 报 `buildReady rejected`。先用 `node --check` 查语法，再看报错的变量。
- **改代码时别同时在渲染**：渲染会并行打开好几页，中途改文件会混用新旧代码。

## 6. 速度

M4 上，6 秒（180 帧）约 40 秒，整首 4 分钟约半小时，放后台跑。每帧都用 JS 逐像素算（背景约 13 万像素，加打光、雨、倒影、亮部提取、光柱）。慢的话先看 `reflect`、`sidewalk` 和 `rays`，不动的部分可以预先画好缓存起来（参考蜡笔版的 `useSet`）。
